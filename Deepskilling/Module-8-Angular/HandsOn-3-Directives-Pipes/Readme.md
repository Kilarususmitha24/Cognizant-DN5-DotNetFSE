# Module 8 - Angular

## Hands-On 3 - Directives and Pipes

### Objective

Create an Angular application demonstrating built-in Angular
directives and pipes.

### Concepts Covered

- Angular Directives
- ngIf
- ngFor
- Event Binding
- Uppercase Pipe
- Lowercase Pipe
- Currency Pipe
- Date Pipe

### Application

The application displays a list of employees using `ngFor`.

The employee table can be displayed or hidden using `ngIf`.

Angular pipes are used to format employee information.

### Directives Used

```html
*ngIf
*ngFor
```

### Pipes Used

```text
uppercase
lowercase
currency
date
```

### Run

```bash
cd directives-pipes-app

npm install

ng serve
```

Open:

```text
http://localhost:4200
```

- Angular 20
- TypeScript
