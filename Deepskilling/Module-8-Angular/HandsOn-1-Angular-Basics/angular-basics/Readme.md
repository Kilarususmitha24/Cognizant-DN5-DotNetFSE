# Module 8 - Angular

## Hands-On 1 - Angular Basics

### Objective

Create a basic Angular application using Angular CLI and
understand the Angular project structure.

### Topics Covered

- Angular CLI
- Angular Project Structure
- Components
- TypeScript
- HTML Templates
- CSS
- Interpolation
- Data Binding

### Project

`angular-basics`

### Run the Application

```bash
cd angular-basics

npm install

ng serve
```

Open:

http://localhost:4200

### Expected Output

The application displays:

- Angular Hands-On 1
- Welcome to Angular
- Student Name
- Course
- Module
- Hands-On information
