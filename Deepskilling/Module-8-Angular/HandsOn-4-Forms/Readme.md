# Module 8 - Angular

## Hands-On 4 - Angular Forms

### Objective

Implement Template-Driven and Reactive Forms in Angular.

### Concepts Covered

- Angular Forms
- Template-Driven Forms
- Reactive Forms
- FormsModule
- ReactiveFormsModule
- ngModel
- FormGroup
- FormControl
- Validators
- Form Validation
- Event Binding
- Property Binding

### Template-Driven Form

The template-driven form collects:

- Employee Name
- Email
- Department

### Reactive Form

The reactive form collects:

- Employee Name
- Email
- Salary

Validation is implemented using Angular validators.

### Run

```bash
cd forms-app
npm install
ng serve
```

Open:

```text
http://localhost:4200
```

### Technologies

- Angular 20
- TypeScript
- HTML
- CSS
- Angular Forms
